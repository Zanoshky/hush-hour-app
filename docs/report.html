Before you write

  • Search the open issues first. If yours is there, add a thumbs up or a comment.
  • Check the questions and fixes page.
  • One problem per report makes it faster to fix.

What helps

App version
Android settings, Apps, Hush Hour. The version is near the bottom of that page.
Phone model and Android version
Android settings, About phone.
Which screen or sound
Home, a sound by name, the timer, Mixes, Settings, the notification or the widget.
Steps
What you did, one step per line, so we can do the same.
Expected and actual
What you thought would happen, and what happened.
A picture or a recording
A screenshot or a short screen recording. Drag it into the form.

Issues on GitHub are public. Before you attach a screenshot, crop or cover anything private.
